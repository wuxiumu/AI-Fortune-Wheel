# 吃瓜命理盘 · 改进路线图

## 📌 当前状态 v1.2.0

✅ Phase 1 & 2 已完成！

## 🚀 Phase 2 · 中期（1 个月） ✅ 已完成

### 2.1 内容扩展 ✅
- [x] **明星数据库**：52 位常见明星的生肖/星座映射，支持搜索和自动匹配
- [x] **生日换算**：用户输入生日自动计算生肖/星座，三种输入模式（搜索/生日/手动）
- [ ] **CP 档案**：为热门 CP 预置「官方解读」（待补充内容）
- [ ] **历史瓜单**：整理过往经典绯闻 CP 案例（待补充内容）

### 2.2 功能扩展 ✅
- [x] **收藏 / 历史记录**：localStorage 持久化，最多 50 条，支持收藏和删除
- [x] **CP 排行榜 UI**：热门 CP 榜单展示，金银铜牌样式，实时热度
- [ ] **多人模式**：3 人及以上的「吃瓜群聊」匹配矩阵
- [ ] **时间线模式**：一对 CP 在不同年份/不同宫位下的关系变化

### 2.3 技术架构 ✅
- [x] **SEO 优化完整化**：为每个子页面生成独立 meta 和 Open Graph 标签
- [x] **前端单元测试**：为 engine.js 添加测试用例，覆盖核心算法
- [ ] 引入 Vite 构建：处理 CSS / JS 合并压缩
- [ ] 添加 Service Worker 支持 PWA 离线访问

## 📚 文档维护约定

1. 本路线图每月至少 review 一次，由产品负责人更新

3. 重大决策（如引入后端、商业化）需要在本文档记录理由与备选方案

## 🤝 贡献指南

欢迎 PR！提交前请：
1. 保证纯函数可测（如 engine.js 的函数）
2. CSS 改动遵循 BEM 或现有命名规范
3. 新增页面复用 `layout.css` 与 `footer` 组件
4. 文案风格遵循「理性吃瓜、娱乐第一」的调性
5. 运行 `npm run lint` 确保代码质量

详见 `README.md`。
