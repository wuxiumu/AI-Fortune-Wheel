## 🎯 产品定位

### 核心理念

将东方命理智慧与西方占星学结合，为AI领域的企业家、投资人和科技领袖提供独特的"缘分测试"和"商业契合度分析"。

### 目标用户

1. **企业家/创始人**: 寻找合作伙伴、投资人、技术顾问
2. **投资人/VC**: 评估创业者、团队的"缘分"和契合度
3. **科技从业者**: 了解行业人脉的"命理关系"
4. **商业分析师**: 研究企业间的"化学反应"

### 差异化价值

- **专业领域**: 专注AI/科技领域，数据更精准
- **国际化**: 支持多语言，面向全球用户
- **商业化**: 提供付费深度分析和报告
- **社交属性**: 可分享测试结果，促进商业社交

## 🧮 测试算法设计

### 1. 商业契合度算法 (Business Compatibility Score)

#### 输入参数

```javascript
{
  person1: {
    zodiac: '金牛',      // 生肖
    constellation: '白羊', // 星座
    industry: 'AI芯片',   // 行业
    role: 'CEO',         // 角色
    company_stage: 'IPO'  // 公司阶段
  },
  person2: {
    zodiac: '狮子',
    constellation: '射手',
    industry: '大模型',
    role: 'CTO',
    company_stage: 'B轮'
  }
}
```

#### 评分维度

1. **命理契合度** (40%)
   - 生肖六合/三合 (20分)
   - 星座三分相/六分相 (20分)

2. **行业协同度** (30%)
   - 同行业 +15分
   - 上下游 +10分
   - 互补行业 +5分

3. **角色匹配度** (20%)
   - CEO + 投资人 = 18分
   - CEO + CTO = 15分
   - 创始人 + 联合创始人 = 20分

4. **阶段匹配度** (10%)
   - 早期 + 早期 = 8分
   - 成长期 + 成长期 = 10分
   - 成熟期 + 早期 = 5分

#### 输出结果

```javascript
{
  score: 85,           // 总分 (0-100)
  compatibility: 'high', // high/medium/low
  tags: ['行业协同', '命理相合'],
  blurb: '这对组合在AI芯片和大模型领域有极强的协同效应，...',
  business_insights: [
    '建议合作方向：AI芯片+大模型优化',
    '潜在冲突：资源分配、决策权',
    '成功概率：85%'
  ]
}
```

## 💰 付费模式设计

### 核心理念

**轻量级运营**：通过企业微信完成支付和交付，无需复杂支付系统。所有数据以 Markdown 文件存储，便于维护和迁移。

### 支付方式

**企业微信转账**
- 用户通过企业微信转账到指定账号
- 人工确认后手动开通权限
- 简单、直接、无需第三方
- 适合中国用户和海外市场

### 套餐设计

#### 1. 免费体验 (Free) - $0

**功能**:
- 每日 3 次免费测试
- 基础结果展示（分数、标签）
- 公开名人/企业数据库
- 基础分享功能

**限制**:
- 无详细分析
- 无历史记录
- 无批量测试
- 含水印

#### 2. 单次报告 (Pay-per-report) - ¥99 / $14.99

**功能**:
- 单次深度分析
- 完整报告（PDF）
- 商业建议
- 7天有效期
- 无水印

**交付方式**:
- 企业微信转账确认
- 手动发送报告链接
- 或邮箱发送 PDF

#### 3. 月度会员 (Pro Monthly) - ¥199 / $29.99/月

**功能**:
- 无限次测试
- 详细分析报告
- 完整历史记录
- 批量测试（最多10对）
- 无水印
- 优先客服

**独家功能**:
- 商业契合度详细分析
- 合作建议
- 风险提示
- PDF报告导出
- 邮件订阅（每周AI行业报告）

#### 4. 年度会员 (Pro Yearly) - ¥1599 / $229.99/年 (省40%)

**功能**:
- 包含月度会员所有功能
- 额外赠送 2 个月
- 专属客服群
- 优先体验新功能

#### 5. 企业版 (Enterprise) - ¥3999 / $599.99/年

**功能**:
- 团队账号（最多5人）
- 无限批量测试
- 自定义报告模板
- 专属客服

**独家功能**:
- 企业配对报告
- 投资分析

### 5. 性能优化

由于使用文件存储，需要注意性能优化：

#### 缓存策略
```php
// 使用文件缓存减少读取
function getCachedData($key, $callback, $ttl = 3600) {
    $cacheFile = __DIR__ . "/../cache/{$key}.json";
    
    if (file_exists($cacheFile) && time() - filemtime($cacheFile) < $ttl) {
        return json_decode(file_get_contents($cacheFile), true);
    }
    
    $data = $callback();
    file_put_contents($cacheFile, json_encode($data), LOCK_EX);
    return $data;
}

// 使用示例
$personalities = getCachedData('personalities', function() {
    return readMarkdownData('ai_personalities');
}, 3600); // 缓存1小时
```
