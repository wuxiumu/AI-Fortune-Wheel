## 数据说明

### 字段说明

| 字段 | 说明 | 必填 |
|------|------|------|
| 国家 | 公司所在国家 | ✅ |
| 成立时间 | 公司成立年份 | ✅ |
| 估值 | 公司估值（美元） | ✅ |
| 主要产品 | 核心产品，逗号分隔 | ✅ |
| 行业标签 | 行业标签，逗号分隔 | ✅ |
| 创始人 | 创始人姓名，逗号分隔 | ✅ |
| 简介 | 简短介绍 | ✅ |
| 融资阶段 | 融资阶段 | ✅ |
| 状态 | active/inactive | ✅ |

### 融资阶段说明

- `Pre-IPO`: IPO前
- `Series A/B/C/...`: A/B/C轮等
- `IPO`: 已上市
- `子公司`: 母公司子公司
- `自筹资金`: 自筹资金，未融资

### 状态说明

- `active`: 运营中
- `inactive`: 已关闭
- `acquired`: 被收购
