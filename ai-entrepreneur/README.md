# AI Fortune Wheel - Global Entrepreneur Edition

> Discover business compatibility in the AI world

## 📋 项目信息

- **项目名称**: AI Fortune Wheel (AI 命理盘)
- **目标市场**: 海外企业家、投资人、科技从业者
- **商业模式**: 免费增值 + 企业微信付费

5. **分享功能**: 将测试结果分享到社交媒体

- **100+ AI 名人**: 包括 Sam Altman、Elon Musk、Jensen Huang 等
- **65+ AI 企业**: 包括 OpenAI、NVIDIA、Anthropic 等
- **持续更新**: 定期添加新的 AI 领袖和企业

## 📊 测试算法

### 人物配对算法

**评分维度** (100分制):

1. **命理契合度** (40分)
   - 生肖六合/三合: +20分
   - 星座三分相/六分相: +20分

2. **行业协同度** (30分)
   - 同行业: +15分
   - 上下游: +10分
   - 互补行业: +5分

3. **角色匹配度** (20分)
   - CEO + 投资人: +18分
   - CEO + CTO: +15分
   - 创始人 + 联合创始人: +20分

4. **阶段匹配度** (10分)
   - 早期 + 早期: +8分
   - 成长期 + 成长期: +10分
   - 成熟期 + 早期: +5分

### 企业配对算法

**评分维度** (100分制):

1. **产业链关系** (40分)
   - 上下游关系: +20分
   - 战略合作: +15分
   - 竞争关系: -10分

2. **发展阶段匹配** (20分)
   - 互补阶段: +10分
   - 相同阶段: +5分

3. **技术协同** (20分)
   - 技术互补: +15分
   - 技术重叠: -5分

4. **市场协同** (20分)
   - 市场互补: +15分
   - 市场重叠: -5分

## 🛠️ 开发指南

### 添加新名人

编辑 `data/ai_personalities.md`，添加以下格式：

```markdown
### 姓名
- **公司**: 公司名称
- **职位**: 职位
- **生日**: YYYY-MM-DD
- **星座**: 星座名
- **生肖**: 生肖
- **标签**: 标签1、标签2
- **简介**: 简介内容
```

### 添加新企业

编辑 `data/ai_companies.md`，添加以下格式：

```markdown
### 企业名称
- **国家**: 国家
- **成立时间**: YYYY
- **估值**: $XB
- **主要产品**: 产品1、产品2
- **行业标签**: 标签1、标签2
- **简介**: 简介内容
```

### 修改样式

编辑 `css/style.css`，使用 CSS 变量自定义主题：

```css
:root {
  --primary: #0066CC;
  --secondary: #6B46C1;
  --gold: #FFD56B;
  /* ... 更多变量 */
}
```

### 修改算法

编辑 `js/app.js` 中的 `calculateCompatibility` 函数，调整评分权重。
